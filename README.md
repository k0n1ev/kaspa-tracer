# Kaspa Deep Origin Tracer

Kaspa Deep Origin Tracer is an interactive blockchain explorer tool built for the Kaspa network. It uncovers the true origin of any Kaspa balance by recursively tracing funds through the full UTXO graph back to mining rewards or known entities (like exchanges).

## Features
- Deep, recursive UTXO tracing for any Kaspa wallet.
- Distinguishes between mining rewards, known entities, and unresolved history.
- Clickable wallet addresses for intuitive deep-diving.
- Persistent history stack with a back navigation button.
- Clean, dark-themed UI built with TailwindCSS.
